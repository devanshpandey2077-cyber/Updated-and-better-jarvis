# Updated-and-better-jarvis
J.A.R.V.I.S is a simple voice-controlled assistant built using Python. It listens to user commands, processes them, and performs actions such as opening applications or responding via speech.
How It Works
listener.py → Captures and processes voice input
executor.py → Executes commands (open apps, speak, etc.)
main.py → Controls the flow of the program
init.py → Makes the folder a Python package
Features
Voice recognition using microphone
Converts speech to text
Opens applications like Chrome, Notepad, Calculator
Text-to-speech response
Modular and clean code structure
